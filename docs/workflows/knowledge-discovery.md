# Knowledge Discovery Workflow

Use for understanding, reconstruction, documentation, or evidence-backed analysis.

1. Define the question.
2. Discover candidate evidence.
3. Rank evidence by directness and authority.
4. Extract concrete facts with file/symbol references.
5. Identify contradictions, gaps, and stale documentation.
6. Build the smallest coherent model that answers the question.
7. Send the result to an independent critic.
8. Publish confirmed facts, inferences, and unresolved gaps separately.

Code can establish what a system does; it may not establish why a historical decision was made. Do not invent intent.

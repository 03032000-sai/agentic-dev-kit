# Release Readiness
Verify acceptance criteria; build requirement→design→implementation→test trace; review diff for scope drift; run clean build/tests/package validation; review security/dependencies; verify observability and rollback; list unresolved risks/exceptions; fresh critic produces final findings. Do not declare readiness with blocking failures or unknown critical validation.

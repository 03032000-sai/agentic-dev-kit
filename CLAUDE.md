# Claude Code Project Instructions

`AGENTS.md` is the canonical engineering operating contract.

Before substantial work:
1. read `AGENTS.md`;
2. identify the appropriate workflow skill under `.claude/skills/`;
3. use specialist agents from `.claude/agents/` when role isolation improves quality;
4. keep authoring and independent critique separate;
5. preserve evidence and validation results across handoffs;
6. require human approval for destructive, irreversible, security-sensitive, credential-sensitive, or production-impacting actions.

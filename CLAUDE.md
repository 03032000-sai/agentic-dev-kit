# Claude Code Instructions

This repository uses a shared vendor-neutral operating contract.

Before substantial work:
1. read `AGENTS.md`;
2. follow the relevant workflow under `docs/workflows/`;
3. use a matching skill under `.claude/skills/`;
4. use the role definitions under `.claude/agents/` when separating responsibilities;
5. preserve separation between discovery, system design, implementation design, implementation, and critique;
6. treat deterministic validation as authoritative;
7. request human approval before destructive, irreversible, security-sensitive, or production-impacting actions.

`AGENTS.md` is the canonical policy. Do not duplicate it here.

# Map Critic

Read-only, fresh-context.

Review the map against the discovery question and authoritative repository evidence. Check for missing entry points/boundaries, unsupported relationships, inferred edges presented as confirmed, ignored tests/config/deploy evidence, stale docs treated as runtime fact, excessive irrelevant detail, and missing unknowns.

Classify findings BLOCKING / IMPORTANT / ADVISORY. Do not silently repair the map.

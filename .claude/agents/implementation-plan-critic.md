# Implementation Plan Critic

Review the approved system design, technical plan, and relevant repository evidence.

Check exactness of files/symbols/APIs/schemas, feasibility against current code, hidden architectural decisions, migration/compatibility, error contracts, test completeness, telemetry, rollout/rollback, executable validation commands, and requirement traceability.

Classify findings and issue a Gate B recommendation. Architectural gaps must reopen Gate A.

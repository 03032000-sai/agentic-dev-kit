# Security Remediation
Establish finding source and affected component; confirm exploitability/reachability where evidence permits; classify without exaggeration; choose smallest durable fix; preserve auth and least privilege; add security regression tests when feasible; run deterministic scanners/tests; critic reviews bypasses/new exposure/fail-open behavior; require human approval for sensitive/destructive actions. For deeper tool-specific guidance, see the `semgrep-sast-rules`, `trivy-sca-scanning`, `mitre-attack-mapping`, `transitive-dependency-remediation`, and `vuln-enrichment-prioritization` skills.
